What exists in this repo (branch claude/new-session-wfy9du)
- CONTRACT.json.txt: JSON the TV polls from GET http://<mac-ip>:8787/api/overlay every 3s.
- tv-app/: Android app, package au.home.betoverlay. One AccessibilityService draws the panel as
  TYPE_ACCESSIBILITY_OVERLAY (not focusable, not touchable) and filters only two remote keys.
  Prebuilt APK: tv-app/dist/bet-overlay-debug.apk. Builds with ./gradlew assembleDebug (needs Android SDK).
  NOT yet run on any device.
- scripts/setup-tv.sh <TV_IP:5555> http://<mac-ip>:8787 : connects, prints device info and Kayo/NBA
  packages, installs APK, appends our service to enabled_accessibility_services, sets TCL AUTO_START
  appop, whitelists from doze, configures the server URL. Needs `adb` on PATH:
  export PATH="$HOME/platform-tools:$PATH"
- scripts/tv-keylog.sh <TV_IP>: logcat of key codes (tag BetOverlay) to choose the two keys.
- server/: Node backend + phone page. NOT yet verified by anyone: the cloud session handed off before its
  review. Before relying on it: npm install, npm test, start it, open the phone page, add a manual bet
  against a real ESPN game, and check GET /api/overlay matches CONTRACT.json.txt. Fix what fails.
